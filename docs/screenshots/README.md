# Control-plane TUI evidence

`control-plane-tui.png` is a browser-rendered ANSI terminal capture of the actual
TUI connected with `--server` to an isolated control-plane server. It shows
`/help`, including stop, settle, explicit unsettle, and continue. The terminal
capture preserves the TUI's ANSI formatting; no model requests or workspace
changes were made to create this evidence.

# Web grid evidence

These captures use deterministic mocked API/WebSocket data, not live projects or
paid model turns. Generated by `TED_WEB_RECORD=1 npx playwright test grid.spec.ts`
in `web/` after the Inter / IBM Plex Mono grid rollout.

Context is now read-only footer metadata. In the recording, settings are entered
through the supported settings deep link, not by clicking the context readout.
The test suite also attaches captures at 320, 768, and 1920px in both themes.
Older screenshots in this directory document earlier work, not the current grid.
