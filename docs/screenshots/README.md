# Control-plane TUI evidence

`control-plane-tui.png` is a browser-rendered ANSI terminal capture of the actual
TUI connected with `--server` to an isolated control-plane server. It shows
`/help`, including stop, settle, explicit unsettle, and continue. The terminal
capture preserves the TUI's ANSI formatting; no model requests or workspace
changes were made to create this evidence.

# Sending from an already-bottom viewport

The regression reproduces a scroller state that is paused by a horizontal/touch
intent even though the transcript is still at its bottom. Previously, sending
then left the viewport 198px above the new end in this fixture. Successful local
sends now explicitly resume following through subsequent content/layout updates.

- [Before: new content remains below the viewport](web-send-scroll-before.png)
- [After: sending resumes bottom-following](web-send-scroll-after.png)
- [Fixed send flow recording](web-send-scroll-demo.webm)

These captures use Chromium with an iPhone-sized viewport and a replayed
`touchmove` handler, not a physical iPhone gesture. The same regressions run in
WebKit through `npm run test:iphone`; mobile reading-position setup replays touch
intent and scroll position because Playwright has no touch-pan API. Separate
cases cover composer shrink, queued turns, failed/slow sends, reading during a
pending request, and late acknowledgements after changing chats.

# Running agent emphasis (issue #6)

These captures use deterministic mocked API/WebSocket inventory, not live projects
or paid model turns. Reproduce from `web/` with:

```sh
TED_WEB_RECORD=1 npx playwright test e2e/agent-running.spec.ts
```

- [Light theme: selected and unselected running chats](web-agent-running-light.png)
- [Dark theme: selected and unselected running chats](web-agent-running-dark.png)
- [Reduced motion: static border and readable label](web-agent-running-reduced-motion.png)
- [Light-theme animation recording (WebM)](web-agent-running-demo.webm)

The recording includes a full eight-second border-beam cycle, followed by reduced
motion and inventory state changes. Idle, stopping, held and settled chats do not
receive the running treatment. Captured with Playwright Chromium at 1440 × 960;
Playwright scales the recording to its default video size.
